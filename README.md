# Badminton Analysis

배드민턴 경기 결과를 기록하고 분석하기 위한 개인용 웹 서비스

## 주요 기능

### 선수 관리

- 선수 등록
- 선수 수정
- 활성 / 비활성 관리
- 승급 이력 관리

### 경기 관리

#### 종목

- 남복
- 여복
- 혼복

#### 기능

- 경기 등록
- 경기 수정
- 경기 조회
- 경기 삭제

### 분석 기능

#### 선수 분석

- 총 경기수
- 총 승 / 패
- 승률
- 최고 연승
- 현재 연승

#### 종목별 분석

- 남복 승률
- 여복 승률
- 혼복 승률

#### 파트너 분석

- 함께 뛴 횟수
- 파트너별 승률
- 최고의 파트너

#### 상대 전적

- 선수 간 전적
- 최근 전적

#### 성장 분석

- 최근 30일 승률
- 최근 90일 승률
- 최근 1년 승률
- 연도별 승률
- 급수별 상대 승률

## 선수 정보

### 등록 항목

- 이름
- 급수 (S, A, B, C, D)
- 생년
- 성별
- 활성 여부

### 중복 제한

아래 정보가 모두 같을 경우 등록 불가

- 이름
- 급수
- 생년
- 성별
